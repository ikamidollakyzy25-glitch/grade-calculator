# Grade Calculator

A simple console application written in C++ for teachers to calculate students' average scores, assign letter grades, and view overall class statistics.

## Requirements
- The program shall accept a student's name and 5 integer scores between 0 and 100.
- The program shall reject any score outside the 0–100 range, display an error message, and prompt the user to re-enter the score.
- The program shall calculate the student's average score and assign a letter grade based on the grading scale.
- The program shall repeat the input process for multiple students until the user enters `end` as the student's name.
- The program shall display the total number of entered students and the overall class average upon termination.

## Grading scale
| Grade | Average |
|-------|---------|
| A | 90 - 100 |
| B | 75 - 89.99 |
| C | 60 - 74.99 |
| F | Below 60 |

## How to run
1. Open https://www.onlinegdb.com and choose **C++** in the top-right corner.
2. Paste the code from `main.cpp` into the editor and click **Run**.
